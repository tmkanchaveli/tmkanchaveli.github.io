Privacy policy

This policy describes the independent personal desktop utility, Codex Local Email Watcher, maintained by the owner of the tmkanchaveli GitHub account.

Google data accessed

With the owner's consent, the utility uses Gmail read-only access to verify the connected mailbox and search selected conversations. It retrieves message IDs, conversation IDs, labels, timestamps, sender and reception-authentication headers, and text or HTML message bodies for relevant candidates. It does not download attachments or follow message links.

Purpose and use

This information is used only to identify authorized instructions, verify the sender and conversation, avoid duplicate execution, route accepted requests to the owner's designated Codex tasks, and diagnose delivery or authorization failures. Quoted or forwarded content is not independent authorization.

Sharing and processing

Accepted instruction text and identifying receipt information are passed to the owner's Codex desktop tasks. Those tasks use OpenAI services to process requests under the applicable OpenAI terms and the owner's account settings. Separately authorized task tools may perform requested actions or send completion replies; the watcher itself has no Gmail send permission.

The watcher does not sell Google user data, use it for advertising, or independently use it to train models. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and protection

OAuth credentials are stored on the owner's Windows computer using Windows user-scoped encryption. Message receipts and selected request text are stored locally with file permissions restricted to the owner, system administrators and Windows SYSTEM. Receipt text is not separately encrypted by this utility. This public website and repository contain no mailbox messages, credentials or task receipts.

Retention and deletion

Local receipts are retained to support deduplication and recovery until the owner removes them. The owner can stop the scheduled watcher, delete its local credentials and records, and revoke access in Google account connections. Revoking Google access prevents further mailbox reads; it does not delete records already stored in Codex or other services.

Website hosting

This information website has no application forms, analytics scripts, cookies set by the site, or mailbox connection. GitHub Pages may collect technical access logs, including IP addresses, under the GitHub Privacy Statement.

Contact and changes

Questions can be directed to the maintainer through the GitHub profile. This policy will be updated if the utility's data practices change.
