Personal desktop utility

Email instructions, delivered to the right task.

A local utility for its owner's workflow. It reads selected Gmail conversations and routes verified, directly authored instructions to designated tasks in the Codex desktop app.

What the utility does

The watcher checks selected conversations locally. Empty checks do not invoke an AI model. It accepts only the configured sender, verifies Gmail authentication and conversation identity, and records message IDs to prevent duplicate delivery.

Google access

The utility requests Gmail read-only access through Google's OAuth consent screen. It reads message headers and text needed for the selected conversations. It does not use this permission to send, delete or modify email.

Local operation

Credentials are encrypted for the owner's Windows account. Selected instruction text and processing receipts are stored locally with restricted file access. Accepted instructions are passed to the owner's Codex tasks for processing. The utility can queue instructions while Codex is closed.

Personal use

This is an independent personal automation, not a public email service or an official Google or OpenAI product. This website provides information only; it offers no account registration, mailbox connection or downloadable credentials.
